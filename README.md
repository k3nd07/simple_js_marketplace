# 🛒 Bazar — Lightweight Single-File Marketplace

**Bazar** — это минималистичное и быстрое веб-приложение маркетплейса, написанное на чистых веб-технологиях (Vanilla JS, CSS3, HTML5) без использования сторонних фреймворков и библиотек. Весь проект содержится в одном файле `index.html`.

## 🌟 Особенности

- **Полная автономность:** Весь HTML, CSS и JavaScript находятся в одном файле.
- **Адаптивный интерфейс:** Корректно отображается на ПК, планшетах и мобильных устройствах.
- **Тёмная тема:** Автоматическое переключение интерфейса в зависимости от системных настроек пользователя (`prefers-color-scheme`).
- **Каталог товаров:**
  - Фильтрация по категориям (*Электроника, Дом, Одежда, Спорт, Книги*).
  - Динамический поиск по названию товара и продавцу.
  - Сортировка по цене (дороже/дешевле) и рейтингу.
- **Корзина покупок:**
  - Добавление и удаление товаров.
  - Изменение количества позиций с мгновенным пересчетом итоговой суммы.
  - Оформление заказа.
- **Публикация товаров:** Модальное окно для добавления новых товаров в каталог.
- **Сохранение состояния:** Использование `localStorage` браузера для сохранения списка товаров, содержимого корзины и истории заказов.

## 🚀 Быстрый старт

1. Скачайте файл `index.html`.
2. Откройте его в любом современном веб-браузере.

Или просмотрите демонстрацию через [GitHub Pages](https://your-username.github.io/your-repo-name/) *(замените ссылку на свою после публикации)*.

## 🛠 Технические подробности

- **Без сторонних зависимостей:** Нет React, Vue, jQuery или Tailwind.
- **Состояние (Persistence):** 
  - `bz_p` — список товаров.
  - `bz_c` — текущая корзина.
  - `bz_o` — оформленные заказы.
